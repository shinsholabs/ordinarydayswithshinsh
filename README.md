# 평범한 날에, 신승호

버전: **v1.10**

날짜별 신승호 관련 기사와 대표사진을 보여 주는 Streamlit 앱입니다. 사진과 기사 제목 모두 원문 링크로 연결됩니다.

## Streamlit Cloud 배포

1. 이 폴더의 내용을 GitHub 저장소에 올립니다.
2. `data/named.xlsx`에 대표 기사 파일을, `data/all.xlsx`에 전체 기사 파일을 넣습니다.
3. 대표이미지 URL이 없는 카드에 사용할 PNG 파일을 `data/logo.png`로 넣습니다.
4. Streamlit Cloud에서 저장소를 선택한 뒤, 메인 파일을 `app.py`로 지정합니다.

앱은 `data/named.xlsx`의 6번째 열에 저장된 대표사진 주소를 사용하므로 기사 페이지를 매번 열지 않습니다. 사진은 서버에서 360px WebP 썸네일로 줄인 뒤 디스크 캐시에 저장해 모바일 데이터 사용량을 줄입니다. 대표사진 주소가 비어 있으면 `data/logo.png`를 표시합니다.

엑셀은 `날짜`, `시간`, `매체명`, `제목`, `url`, `대표이미지` 열을 사용합니다. 첫 줄에 열 제목이 있는 형식과 열 제목 없이 기사 데이터만 있는 형식을 모두 읽습니다. 대표이미지 열은 선택 항목이지만 `named.xlsx`에서는 사용하는 것을 권장합니다.

## 화면 구성

- 상단의 작은 숫자 입력칸에서 연도 없이 월과 일만 고르면, 같은 월·일의 모든 연도 기사가 연도별로 표시됩니다. 숫자를 직접 입력하거나 `◀/▶` 버튼으로 조절할 수 있습니다.
- 날짜의 기본값은 한국시간 기준 오늘의 월·일입니다. 연도와 같은 연도의 기사 모두 최신 기사부터 오래된 기사 순으로 표시합니다.
- 사진은 모바일을 포함해 항상 2열 카드로 표시되고 480×360(4:3) 크기로 통일됩니다. YuNet이 여러 각도와 크기의 얼굴을 인식한 뒤 가장 큰 얼굴과 상반신을 중심으로 자릅니다. 얼굴을 찾지 못하면 사진 상단 중앙을 기준으로 4:3 영역을 잡습니다. 기사가 하나만 있어도 카드 폭은 2열 기준으로 유지됩니다.

YuNet 모델 파일이 `data/face_detection_yunet_2023mar.onnx`에 있으면 해당 파일을 사용합니다. 파일이 없으면 첫 실행 때 OpenCV 공식 저장소에서 작은 모델을 한 번 내려받아 임시 저장소에 보관합니다.
- 각 기사는 기사 제목과 해당 사진이 한 카드 안에서 짝을 이루며, 모바일에서도 2열로 표시합니다.
- 기사 제목에는 밑줄을 표시하지 않습니다.
- 기사 제목은 굵게 표시하지 않습니다.
- 전체 화면에는 Streamlit 기본 산세리프 글꼴을 사용합니다.
- 캘린더에서 선택한 월·일을 기준으로 모든 연도의 기사를 표시합니다.
- 기사 목록 위에는 날짜 없이 연도만 표시합니다.
- 기사 목록 아래의 `> 더보기`를 누르면 `data/all.xlsx`에서 같은 월·일의 전체 기사 제목을 연도별로 불러옵니다. 제목을 누르면 원문으로 이동합니다.

일부 언론사는 페이지 접근을 제한하거나 이미지를 외부 사이트에 표시하지 않을 수 있습니다. 이 경우 해당 카드에는 안내 문구가 표시되며 제목을 눌러 원문으로 이동할 수 있습니다.
