# 평범한 날들, 신승호

날짜별 신승호 관련 기사와 기사 속 첫 사진을 보여 주는 Streamlit 앱입니다. 사진과 기사 제목 모두 원문 링크로 연결됩니다.

## Streamlit Cloud 배포

1. 이 폴더의 내용을 GitHub 저장소에 올립니다.
2. `data/named.xlsx`에 기사 엑셀 파일을 넣습니다.
3. Streamlit Cloud에서 저장소를 선택한 뒤, 메인 파일을 `app.py`로 지정합니다.

엑셀은 `날짜`, `시간`, `매체명`, `제목`, `url` 열을 사용합니다. 각 연도별 시트처럼 첫 줄에 열 제목이 있는 형식과, `NAMED` 시트처럼 열 제목 없이 기사 데이터만 있는 형식을 모두 읽습니다.

## 화면 구성

- 상단의 날짜 선택 캘린더에서 날짜를 고르면, 같은 월·일의 모든 연도 기사가 연도별로 표시됩니다. 예: `2026-09-25` 선택 시 2018년 9월 25일, 2019년 9월 25일 등의 기록을 함께 봅니다.
- 사진은 모바일 기준 2열 카드로 표시되고 정사각형 크기로 통일됩니다.
- 카드에는 사진 아래 기사 제목만 표시합니다.
- 캘린더에서 선택한 월·일을 기준으로 모든 연도의 기사를 표시합니다.

일부 언론사는 페이지 접근을 제한하거나 이미지를 외부 사이트에 표시하지 않을 수 있습니다. 이 경우 해당 카드에는 안내 문구가 표시되며 제목을 눌러 원문으로 이동할 수 있습니다.
